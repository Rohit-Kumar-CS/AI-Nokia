# 📊 Telecom AI & Machine Learning Projects (MOP Repository)

## Overview

This repository contains a collection of **Artificial Intelligence, Machine Learning, Data Analytics, SQL, Python, and ETL Method of Procedure (MOP)** projects developed for telecom analytics and AI learning.

The projects cover customer analytics, prediction models, anomaly detection, NLP, data processing, SQL operations, and automation techniques.

---

## 📁 Project Structure

| Project Name                                                                              | Description                                                                                                               |
| ----------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 📂 ANOMALY DETECTION                                                                      | Detect unusual patterns and abnormal behavior in telecom network or customer data using Machine Learning techniques.      |
| 📂 Average Revenue Per User (ARPU) Prediction                                             | Predict customer ARPU using historical telecom usage and billing data.                                                    |
| 📂 Churn Prediction                                                                       | Predict customers who are likely to leave the telecom service using classification models.                                |
| 📂 CUSTOMER SEGMENTATION                                                                  | Group customers into different segments based on usage, revenue, and behavior using clustering algorithms.                |
| 📂 Method of Procedure (MoP) – AI-Assisted Per-Cell Monthly Traffic Forecasting using FPM | Forecast monthly telecom traffic for individual network cells using AI forecasting models.                                |
| 📂 MOP — Build Your First Automated ETL (CSV → Clean CSV)                                 | Create an automated ETL pipeline to clean and transform raw telecom CSV datasets.                                         |
| 📂 MOP – Essential SQL Operations for Telecom Analytics                                   | Learn SQL queries used in telecom analytics including filtering, joins, aggregation, and reporting.                       |
| 📂 MOP – ETL Mini-Project (Customer Profile + Complaints Integration using MySQL)         | Integrate customer profile and complaint datasets using MySQL and ETL processes.                                          |
| 📂 MOP — Simulating Role-Based Access (PII Masking in Python)                             | Implement role-based access control and mask Personally Identifiable Information (PII) using Python.                      |
| 📂 MOP for Exercise 2                                                                     | Practice exercises related to telecom analytics and Python programming.                                                   |
| 📂 MOP for Processing Big Datasets Efficiently (Chunk-Based Reading)                      | Process large telecom datasets efficiently using chunk-based reading in Pandas.                                           |
| 📂 SENTIMENT ANALYSIS                                                                     | Analyze customer feedback and classify sentiments using Natural Language Processing (NLP).                                |
| 📂 TICKET ROUTING (INTENT AI)                                                             | Automatically classify customer support tickets and route them to the appropriate department using Intent Classification. |
